# vpn#

VPN-сервис с отсылкой на C# (Sharp). Читается как «vpn sharp».

Multi-server VPN-стек на **VLESS + Reality (xhttp)** для рынка РФ, с веб-кабинетом,
подписками, оплатой и Telegram-ботом.

## Архитектура (кратко)

```
                 ┌─────────────────────────────────────────────┐
                 │  Панель (control plane)  90.156.221.114      │
                 │                                              │
   клиент ──TLS──▶  :443  Caddy ──▶ 127.0.0.1:3000  vpn-web    │
                 │         └──────▶ Xray (Reality, fallback)    │
   браузер ──────▶  :80/:443  сайт vpnsh.ru / defenceai.ru      │
                 │  :2096 x-ui subscriptions (закрыт наружу)    │
                 │  3x-ui панель :22825 (только localhost)      │
                 │  PGlite (БД сайта)  /opt/vpn-web/pgdata      │
                 └───────────────┬─────────────────────────────┘
                                 │ health/load (8090, только с панели)
        ┌────────────────────────┼────────────────────────┐
        ▼                        ▼                        ▼
   ┌─────────┐             ┌─────────┐             ┌─────────┐
   │ DE node │             │ PL node │             │ NL node │
   │ :443    │             │ :443    │             │ :443    │
   │ Xray    │             │ Xray    │             │ Xray    │
   └─────────┘             └─────────┘             └─────────┘
```

- **Панель** раздаёт подписки сама: роут `/sub/<code>` строит `vless://` из таблицы
  `servers` в PGlite. Порт `2096` (подписки x-ui) — legacy, клиентам не нужен.
- **Ноды** — чистый Xray (VLESS/Reality/xhttp) на `:443`, плюс `loadstat` на `:8090`
  для отдачи процента загрузки панели.

Подробнее — [`docs/architecture.md`](docs/architecture.md).

## Структура репозитория

```
servers/
  nodes/     конфиги и установка VPN-нод (DE/PL/NL)
  panel/     конфиги и установка панели (сайт, x-ui, Caddy, бэкапы)
clients/     клиентские инструкции и формат подписки
docs/        архитектура, безопасность, бэкапы, восстановление
```

Каждый каталог содержит `install-*.sh` — идемпотентный установщик, который
раскладывает конфиги и сервисы. Секреты в репозиторий **не коммитятся** —
только шаблоны `.example` и плейсхолдеры.

## Быстрый старт

```bash
# 1. Нода (Ubuntu 24.04)
sudo ./servers/nodes/install-node.sh --country DE --reality-dest www.microsoft.com:443

# 2. Панель (Ubuntu 24.04)
sudo ./servers/panel/install-panel.sh
```

Секреты для панели — в `/etc/vpn-web.env` (см. `servers/panel/vpn-web.env.example`).
